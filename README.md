# 주유창 개인 포트폴리오

기업형 모던 스타일의 반응형 개인 포트폴리오 웹사이트입니다.

## 카테고리 구성

1. **Home** — 포트폴리오 소개 및 메인 비주얼
2. **Profile** — 기본 프로필과 학력
3. **Research & Activities** — 학습 및 활동 이력
4. **Certificate** — AI 윤리 교육 수료 내역 및 검증 링크
5. **AI Projects** — AI 프로젝트를 추가할 공간
6. **Contact** — 마무리 및 연락 섹션

## 실행 방법

별도 빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다. GitHub Pages 또는 Vercel의 정적 사이트로 배포할 수 있습니다.
